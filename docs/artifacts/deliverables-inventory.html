Objects and metadata 4 items

Custom objects versioned under force-app/main/default/objects/. The external callout uses a Named Credential — no Remote Site Setting.

Artifact Type Purpose
Library_Book__c Custom Object Book catalogue. Fields Title__c (formula = Name), Author__c, Available_Copies__c, Total_Copies__c.
Library_Book_Loan__c Custom Object Loan record. Borrower__c (lookup Contact), Book__c (lookup Library_Book__c), Loan_Start_Date__c, Loan_End_Date__c.
LibraryRefresh__c Message Channel Lightning Message Service channel. libraryBookSearch publishes when a loan is created or imported; the lists subscribe and reload.
Open_Library Named Credential Endpoint https://openlibrary.org, anonymous (NoAuthentication). Backs the callout:Open_Library request.

Apex — trigger and business rule 3 items

The core of the challenge: a loan is only registered when a copy is available, and the book's stock is kept in sync.

Artifact Type Purpose
LibraryBookLoanTrigger Apex Trigger Trigger on Library_Book_Loan__c (after insert, after delete). Delegates all logic to the handler.
LibraryBookLoanTriggerHandler Apex Class Bulkified trigger logic. Validates Available_Copies__c, decreases on insert / increases on delete. One FOR UPDATE SOQL + one DML per transaction; blocks with addError(NoAvailableCopiesException).
NoAvailableCopiesException Exception Custom exception (extends Exception) thrown when no copies are available for the loan.

Apex — service layer 3 items

Single entry point for search, import and loan — reused by the interface.

Artifact Type Purpose
LibraryService Apex Class searchBooks — unified search: local SOSL + Open Library, title deduplication and a SOQL backfill against SOSL index lag. importBook — persists an external book as a Library_Book__c. loanBook — throws NoAvailableCopiesException. requestLoan — @AuraEnabled, converts failures into AuraHandledException for the LWC.
OpenLibraryService Apex Class Client for the Open Library Search API via callout:Open_Library. Layered try/catch + defensive parsing; never throws — on failure it degrades to an empty list and search continues with the local catalogue only.
LibraryListController Apex Class getBooks / getRecentLoans (@AuraEnabled(cacheable=true)) for the list components; refreshApex on demand via the LMS channel.

Lightning Web Components 4 items

A DigiLibrary app was created. Its Home page holds libraryBookSearch at the top, with libraryLoanList and libraryBookList side by side below. libraryLoanButton renders inside each search result (and is also reusable standalone on a record page). All UI text and error messages are in English (client requirement).

Artifact Type Purpose
libraryBookSearch LWC Main interface. Search by title or author (local catalogue + Open Library), triggered by a Search button or Enter. Each result shows the available copies with "Request loan", or "Register / Import" when the book is not yet in the catalogue.
libraryLoanButton LWC Reusable loan-request button. Success/error toast, loancreated event. Works embedded in the search or standalone on a Library_Book__c record page.
libraryBookList LWC lightning-datatable of the catalogue (title, author, available, total). Reloads on a LibraryRefresh__c message.
libraryLoanList LWC lightning-datatable of loans, with a per-row "Delete" action (LightningConfirm + deleteRecord). Deleting returns the copy to the collection via the after delete trigger.
